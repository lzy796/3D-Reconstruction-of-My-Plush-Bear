# 毛绒熊三维重建

把 64 张手机照片 + SAM3D 的单视角结果，做成一只**可 360° 观看、带毛绒质感、背面徽章与文字清晰**的数字小熊。

## 先读这个

| 文档 | 内容 |
|---|---|
| [docs/00_项目台账.md](docs/00_项目台账.md) | **唯一真相源**：目标、素材清单、已核实事实、技术路线、进度、决策、风险 |
| [docs/01_术语讲义.md](docs/01_术语讲义.md) | 图形学术语（网格 / UV / PBR / splat / 相机标定 / 投影…） |
| [docs/02_操作手册.md](docs/02_操作手册.md) | 从空场景到成品的逐步操作，每步带验收标准 |

## 目录

```
assets/    64 张原始照片（只读）
sam3d/     object_0.glb（参照曲面）、object_0.ply（96,760 splat，外观主体）
docs/      台账 / 术语 / 手册 / 素材清单 JSON
scripts/   盘点与预览脚本（需 DSH 自带 Python）
work/      中间产物：四视图、清晰度统计、徽章对比、临时 .blend
tools/     Blender 5.3 便携版
```
