# 操作手册：从 Blender 空场景到"背面有徽章的毛绒熊"

> 配套：[项目台账](00_项目台账.md)（事实与决策）· [术语讲义](01_术语讲义.md)（概念）
> 每一步都有 **✅ 验收**：做完应该看到什么。看不到就不要往下走，先按小节末尾的「卡住时」排查。
> 界面名以 Blender **5.3 英文界面**为准；括号里注了中文，个别菜单名在小版本间可能略有差异。

---

## 0. 打开软件

1. 解压后的 Blender 在 `tools\blender-5.3.0-windows-x64\` 里，双击 `blender.exe`。
2. 启动画面点空白处关掉。
3. （可选）`Edit > Preferences > Interface > Language > 简体中文`，重启生效。下文仍用英文名，方便对照教程。

**快捷键先记这 6 个**，全流程只靠它们：

| 键 | 作用 |
|---|---|
| `鼠标中键拖动` | 旋转视角 |
| `Shift + 中键拖动` | 平移视角 |
| `滚轮` | 缩放视角 |
| `小键盘 1 / 3 / 7` | 前视 / 右视 / 顶视；加 `Ctrl` 是反向 |
| `小键盘 0` | 进入 / 退出相机视角 |
| `G` / `R` / `S` | 移动 / 旋转 / 缩放（按完再按 `X`/`Y`/`Z` 锁轴，`Enter` 确认，右键取消） |

> 笔记本没有小键盘：`Edit > Preferences > Input > Emulate Numpad` 打勾，用主键盘数字代替。

## 1. 导入两件东西，确认它们对得上

### 1.1 清空场景

`File > New > General`，然后 `A` 全选、`X` 删除（默认的立方体、灯、相机都删掉）。

### 1.2 导入 splat（外观主体）

把 `sam3d\object_0.ply` 从文件资源管理器**直接拖进 3D 视图**，弹出导入确认后点确认。
菜单路径是 `File > Import > Point Cloud (.ply)`（已实测：5.3 的 PLY 导入器会自动识别 splat 属性，导入后的对象类型是 **Point Cloud**，属性里有 `radiance:base`）。

**✅ 验收：** 视图里出现一只毛茸茸的熊，Outliner（右上角大纲）里多出一个对象，类型显示为 Point Cloud；按 `N` 面板能看到它有 96,760 个点。

### 1.3 先认清方向（30 秒，很关键）

按 `小键盘 1`（前视图，相机站在 −Y 往 +Y 看）。

- 你应该看到**熊的脸**——眼睛、鼻子、领结。**这只熊的脸朝 −Y。**
- 按 `Ctrl + 小键盘 1`（后视图）应看到**后脑勺**。

**✅ 验收：** 熊是**直立**的，不是躺倒的；脸朝 −Y。

> 这一条我已经用 headless 脚本验证过（台账 F11/F12）：导入后两者**天然对齐，不需要手动旋转**。你只需确认看到的是同一只熊。

### 1.4 导入 GLB（贴图案用的参照曲面）

`File > Import > glTF 2.0 (.glb/.gltf)`，选 `sam3d\object_0.glb`。

**✅ 验收：** 又多一只熊，同样直立、脸朝 +Y，位置和 splat 的熊大致重合（可能有一点整体偏移/缩放，正常）。

### 1.5 对齐检查（不要跳过）

1. 选中 GLB 那只，按 `H` 隐藏；再按 `Alt + H` 显示。反复切换，盯住**耳尖、衣服下沿、两只脚**。
2. 如果只是整体平移/缩放差一点：选中 GLB，`G` / `S` 微调即可（先别改形状）。
3. 如果**朝向不同**（一个朝 +Y 一个朝 −Y，或一个躺着）：选中它 `R` `Z` `180` 或 `R` `X` `90`。

**✅ 验收：** 切换显示时，耳朵、衣服、脚落在同一位置，误差小于一个耳朵的厚度。
把差异（尤其需要的旋转角度）记进[台账 §7](00_项目台账.md)。

### 1.6 修掉 GLB 材质里两个会误导眼睛的设置

选中 GLB → 右侧 `Material Properties`（红色圆球图标）：

- `Metallic` 改成 **0**（文件里没写，默认是 1.0＝全金属，看着发灰）。
- `Roughness` 保持 1.0。
- 同一面板下方 `Settings > Backface Culling` **取消勾选**（文件里是单面材质，取消后背面才不会"消失"）。

**卡住时：**

| 症状 | 原因 | 处理 |
|---|---|---|
| 拖进去没反应 | 文件被资源管理器占用 / 拖到了面板上 | 用 `File > Import` 菜单 |
| 熊躺倒 | 轴向 | §1.5 第 3 条 |
| 一片黑或一片白 | 视图着色模式不对 | 右上角四个圆球选 `Material Preview` 或 `Rendered` |
| splat 全是噪点 | EEVEE 抖动透明 | `Render Properties > Sampling` 把 Render 采样提到 128+ |

## 2. 摆一台和 89 号照片一样的相机

目标：让 Blender 里的相机"站"在拍 89 号照片时的位置，这样照片才能准确地投到模型上。

### 2.1 建相机

`Add > Camera`。选中相机，按 `小键盘 0` 进入相机视角。

### 2.2 把照片贴到相机背景

选中相机 → 右侧 `Object Data Properties`（绿色相机图标）→ 展开 `Background Images` → `Add Image` → `Open` → 选
`assets\微信图片_20261125233817_89_64.jpg`。

- `Opacity` 先给 **0.5**：这样能同时看见照片和模型，方便对齐。
- `Depth` 选 `Front`（保证背景图不被模型挡住）。

### 2.3 把相机放到熊的背面

熊的脸朝 −Y，所以**背面在 +Y 一侧**，相机要站在 +Y、朝 −Y 看：

1. 选中相机，`Alt + R` 清空旋转，然后 `R` `X` `-90`（现在相机朝 −Y，画面上下正常）。
2. `G` `Y` `2.5`（退到 2.5 米外，注意是**正的** +Y），`G` `Z` `0.45`（抬到熊胸口高度）。
   > 熊的模型高度约 0.96 个单位。若你的熊看起来太大或太小，先调距离再说。

3. 右侧 `Object Data Properties > Lens > Focal Length` 先设 **50 mm**。

### 2.4 对齐四件事

一边看相机视图（背景图半透明叠在模型上），一边微调：

| 调什么 | 目的 |
|---|---|
| `G Z` 上下移 | 让熊在画面里的**高度位置**对上照片 |
| `G X` 左右移 | 让熊在画面里的**水平位置**对上 |
| `G Y` 前后移 | 改变熊占画面的**大小**（透视会同时变，别一次动太多） |
| `Focal Length` | 大小对了但"透视感"不对时再动它（广角显胖、长焦显扁） |
| `R Z` | 照片里的熊略微侧身时用 |

**对齐顺序：先轮廓，后细节。** 依次对：耳尖 → 头顶 → 两肩外缘 → 衣服下沿 → 两脚外缘。

**✅ 验收：** 把背景图 `Opacity` 拉到 1.0，模型轮廓仍和照片里的熊基本重合（差半个耳朵以内），徽章大致落在衣服背面中央。

### 2.5 留一张基准渲染

`F12` 渲染一张，`Image > Save As` 存成 `work\calib_89.png`。和原照片并排看，确认轮廓对得上。

> 这一步是整个流程里最需要耐心的。**相机没对好，后面的徽章一定偏。** 如果衣服形状怎么都对不上（比如 SAM3D 把背片做鼓了/做平了），才需要回到 §1.5 微调 GLB，或接受"图案位置对、边缘略偏"。

## 3. 从 GLB 上"剥"一块背片，做贴片

思路：贴片不需要新形状，**直接从 GLB 复制衣服背面那一块面**，它天然贴合、轮廓也天然正确。

### 3.1 选中衣服背面的面

1. 选中 GLB，`Tab` 进入编辑模式。
2. `Ctrl + 小键盘 1` 切到后视图（正对熊的背）。
3. 确认 `Alt + Z` 关闭透视选择（X-ray 关），这样框选只选到"看得见的那一层"。
4. 按 `B`，用鼠标框住**整块紫色衣服的背面**（含两枚徽章和下方文字），松手。
5. 如果多选了熊身或手臂：按住 `Shift` + `B`？不对——用 `Alt + A` 先取消全选，改用**多次小框**分别框徽章和文字区，再用 `Ctrl + 小键盘 1` 检查是否漏面。

> 选不干净没关系：这一步先做**小范围 MVP**，只框住**右边那枚系徽**所在的区域即可。验证成功后，再重做一次框住整块背片。

### 3.2 复制成独立物体

1. `Shift + D` 复制，然后**立刻按右键取消移动**（保持在原位）。
2. `P` → `Selection`（分离选中项）。
3. `Tab` 退出编辑模式。Outliner 里多出一个新物体，双击改名为 `patch_back`。

### 3.3 把贴片往外抬一点点

选中 `patch_back`，`Tab` 进入编辑模式，`A` 全选，按 `Alt + S`，输入 `0.003`，回车。`Tab` 退出。
（`Alt + S` 是沿法线"胖/瘦"，正数往外。）

**✅ 验收：** `H` 隐藏 GLB 后，贴片仍然浮在 splat 表面之外，从背面看不会被毛挡住。

### 3.4 用"从视图投影"给贴片生成 UV

1. 保持 `patch_back` 选中，按 `小键盘 0` 回到相机视图。
2. `Tab` 进编辑模式，`A` 全选。
3. 按 `U`，选 **`Project from View`**（不是 Bounds 版）。
4. `Tab` 退出。

**为什么这样做：** 这一步把"相机画面上的位置"直接写成 UV。于是贴片每个顶点都记住了"我在 89 号照片的哪个像素上"，图案自动落位，不用手动挪。

### 3.5 给贴片贴照片

1. 选中 `patch_back` → `Material Properties` → `New`。
2. `Base Color` 左边的小圆点 → `Image Texture` → `Open` → 选 **89 号照片原图**。
3. `Metallic` = 0，`Roughness` = 1.0。
4. 往下找 `Emission` 分组：`Emission Color` 也接同一张 `Image Texture`，`Emission Strength` = **0.5**。
   > splat 是"自带光照"的，不接收场景灯。贴片加一点自发光，亮度才接得上，不会比周围暗一块。

**✅ 验收：** 相机视图里，贴片显示的是照片上那块衣服的像素——徽章、文字应当出现在正确位置。

**卡住时：**

| 症状 | 原因 | 处理 |
|---|---|---|
| 贴片是纯紫色/纯色 | UV 没生成 | 回 §3.4，确认是在**相机视图**里按的 `U` |
| 图案整体偏移 | 相机没对好 | 回 §2.4；先修轮廓 |
| 图案是反的 | 投影方向反了 | 相机应在 **+Y** 侧、朝 −Y 看；检查 `R X` 是不是写成了 `+90` |
| 贴片被毛吃掉 | 抬得不够 | `Alt + S` 加大到 0.006–0.01 |
| 贴片像贴纸浮空 | 抬得太多 | 减到 0.002 以内 |
| 贴片边缘带出背景 | 框选超出了衣服 | 回 §3.1 少框一点 |

## 4. MVP 验收：和照片并排比

1. `H` 隐藏 GLB（只留 splat + 贴片）。
2. `F12` 用相机渲染 → 存 `work\badge_test.png`。
3. 和 89 号照片并排看，只判三件事：

| 判据 | 通过标准 |
|---|---|
| 位置 | 徽章圆心与照片里的位置差 < 徽章半径的 1/5 |
| 清晰度 | 徽章外圈英文能辨认出字母轮廓（不必逐字读清） |
| 融合 | 贴片与周围紫衣看不出明显色差/硬边 |

三条都过 → 这个方案成立，进入 §5 做整块背片。
有一条不过 → 只改那一项，别同时动相机和贴片。

## 5. 扩展到整块背片（两枚徽章 + 文字）

重复 §3.1–§3.5，这次框住**整块紫色背片**，物体命名 `patch_back_full`。

- 先删掉 MVP 的 `patch_back`（`X`）。
- 若贴片边缘出现照片里的背景（肩线外），把那一圈顶点选中删掉（`X > Vertices`），边缘自然收在衣服轮廓内。
- 检查角度：`小键盘 0` 之外，再按 `Ctrl + 小键盘 3`（左后视）和 `Ctrl + 小键盘 1` 附近转动视角，看贴片是否始终贴合。

## 6. 收尾：灯光、渲染、转台

### 6.1 先判断要不要加灯

splat 不接收灯光，贴片有一点自发光。**大多数情况下不需要打灯**——加灯只会照亮贴片、把两者亮度差拉大。

需要打灯的唯一场合：贴片明显偏暗。此时加一盏 `Area Light`，强度很低（10–50 W），只照贴片。

### 6.2 渲染设置

- `Render Properties > Render Engine`：先 `EEVEE`（快），出片前可换 `Cycles`。
- EEVEE：`Sampling > Render` 提到 **128**（splat 用抖动透明，采样低会噪）。
- Cycles：`Device = GPU`，`Sampling > Render` 256 起。

### 6.3 转台

1. `Add > Empty > Plain Axes`，`G Z` 移到熊的中心高度。
2. 选中相机，`Shift` 加选 Empty，`Ctrl + P` → `Object`（相机挂到空物体上）。
3. 选中 Empty，`I` 插入旋转关键帧（第 1 帧），`R Z 360`，在第 240 帧再 `I` 一次。
4. `Timeline` 里把帧范围设 1–240，右键关键帧设 `Linear` 插值。
5. `Render > Render Animation`，输出 `FFmpeg Video`，`H.264`，存 `work\turntable.mp4`。

**✅ 验收：** 视频转一圈，转到背面时徽章与文字清晰可读，转到侧面时贴片不穿帮。

## 8. 如果三次尝试都过不了：三条退路

1. **贴片始终对不齐** → 放弃精确投到曲面，改为"在 GLB 背片上重做 UV（`Smart UV Project`）+ 在图像编辑器里手工把徽章贴上去"。慢，但位置完全可控。
2. **splat 表面和 GLB 表面差太多**（一个鼓一个平）→ 用 GLB 当主体做一版网格 + 毛发，splat 只作参考。会牺牲一部分绒毛真实感。
3. **只要网页能转** → 放弃 splat，交付烘焙好贴图的 GLB（D3），用贴图 + 少量毛发模拟绒毛。
