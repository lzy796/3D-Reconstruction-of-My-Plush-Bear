# 零基础陪跑：把这只小熊做成 3D 模型（7 天）

> 这份手册是给**完全没碰过 3D 软件**的人写的。每一步都写了「点哪里、输什么、你应该看到什么」。
> 需要"为什么"的时候再翻 [plan_no_reshoot.md](plan_no_reshoot.md)，平时不用看。
> 时间：每天 4–6 小时，7 天。新手按熟手的 1.5 倍算，别赶。
> 电脑：8 GB 内存能跑，16 GB 舒服；没有独立显卡也能做，只是最后渲染慢（平时用 EEVEE 预览就行）。

---

## 先搞清楚：我们到底在干什么

做这只熊，跟做手工布偶一个道理，顺序不能乱：

```
① 捏骨架（用几个球拼出胖瘦）        ← 第 1 天
② 修五官（把球表面雕出脸、耳朵、爪）  ← 第 2 天
③ 穿衣服（马甲 + 领结）             ← 第 3 天
④ 把面理顺（减面 + 铺平，准备长毛）  ← 第 4 天
⑤ 植毛（一根根长出来）              ← 第 5 天
⑥ 贴徽章（背面两个圆标 + 两行字）    ← 第 6 天
⑦ 打光拍照（出图、导出）            ← 第 7 天
```

**最容易搞错的两件事，先说在前面：**

1. **第 1 天捏的骨架，要比照片上看到的熊"瘦一圈"。** 因为照片里那个轮廓是"毛的外沿"，你后面还要长 4–5 毫米的毛。现在按轮廓捏，长完毛就变胖熊了。
2. **背面徽章不是"雕"出来的，是"贴"上去的。** 它是平面的刺绣，用一张 4K 贴图 + 一点点凹凸就够了，千万别去建模那些小字。

## 第 0 天：准备（1 小时）

### 0.1 装三个软件（都免费）

| 软件 | 干什么用 | 去哪下 | 装的时候注意 |
|---|---|---|---|
| **Blender 4.2 LTS**（推荐，4.x 都行） | 建模、长毛、渲染，主力 | blender.org/download | 选 LTS 版；下载的是压缩包，解压后双击 `blender.exe` 就能用，不用安装。别装 5.x，界面和本文对不上 |
| **Inkscape** | 画徽章的矢量图（放大不糊） | inkscape.org | 一路下一步 |
| **GIMP** | 修图、做贴图、叠图检查 | gimp.org | 一路下一步 |

> 只装 Blender 也能开始，第 1–5 天都用不到另外两个；第 6 天才需要。

### 0.2 第一次打开 Blender，你看到的是什么

打开后屏幕上会有一个灰色大方块（默认立方体），别慌：

| 位置 | 叫什么 | 干什么 |
|---|---|---|
| 中间一大片 | **视口** | 你捏模型的地方 |
| 左上角 | 工具栏 | 各种笔刷、选择工具 |
| 右上角 | 大纲 | 场景里有啥（相机、灯、模型）都列在这 |
| 右下角 | 属性面板 | 一排小图标，改参数都在这里 |
| 最上面一排 | 工作区标签 | Layout（默认）、Modeling、Scripting… 我们要用 Layout 和 Scripting |

**第一步动作**：把默认的立方体删掉——点它，按 `X`，再点"删除"。

### 0.3 只记这 7 个操作（够用一整周）

| 操作 | 怎么做 | 什么时候用 |
|---|---|---|
| 转视角 | 按住**鼠标中键**拖 | 想看侧面、背面 |
| 平移 | `Shift` + 鼠标中键拖 | 画面跑偏了 |
| 缩放 | 滚轮 | 看不清细节 |
| 切前视图 | **数字键盘 1** | 每天都要用几十次 |
| 切正交/透视 | **数字键盘 5** | 量比例时必须正交（否则有近大远小） |
| 移动/缩放/旋转 | `G` / `S` / `R` | 调大小位置 |
| 撤销 | `Ctrl+Z` | 手滑了 |

> 笔记本没有数字键盘？按 `文件 > 偏好设置 > 输入 > 模拟数字键盘`，勾上后用主键盘的 1/3/7 代替。

### 0.4 三个"我怎么知道做对了"的自检动作

1. **看前视图**（数字键盘 1）：小熊左右是否对称？
2. **转一圈**（按住中键拖）：有没有突然穿帮的地方（比如腿断在身体里）？
3. **按 `N`**（侧边栏）：看选中物体的大小数字，跟手册里的尺寸对不对得上？

### 0.5 建好文件夹（很重要，别偷懒）

在 `D:\3D-Reconstruction-of-My-Plush-Bear\traditional_route\` 下面建这四个文件夹：

```
blend\      ← 存 .blend 工程文件
render\     ← 存的图
textures\   ← 贴图（徽章、毛流）
export\     ← 最后导出的 glb/fbx
```

### 0.6 每天的两个习惯

- **开工前**：`文件 > 另存为` 一个带日期的名字，比如 `bear_day3_v1.blend`。
- **收工前**：再另存一个 `bear_day3_v2.blend`，并且**渲染一张前视图存到 render\ 里**。

为什么要每天存两个版本？因为第 5 天长毛之后如果发现第 2 天脸雕歪了，你得能退回去。这是新手最容易哭的地方。

## 第 1 天：搭骨架（3 小时）

### 1.1 今天的目标

用 7 个球拼出一只"没有五官的小熊面团"，并且和照片上的轮廓对得上。

### 1.2 一键生成（推荐做法，5 分钟）

1. 打开 Blender → 删掉默认立方体。
2. 顶部工作区点 **Scripting**（最右边那个）。
3. 点左上角 **Open**（打开）→ 找到：
   `D:\3D-Reconstruction-of-My-Plush-Bear\traditional_route\scripts\setup_scene.py`
4. 点右上角 ▶ 按钮（或按 `Alt+P`）运行。
5. 屏幕下方会滚动出一堆 `[bear] ...` 的文字，说明在干活。
6. 切回 **Layout** 工作区，按**数字键盘 1**。

**你应该看到**：一只由球体合体成的小熊（没有五官），背后有一张彩色参考图（可能是前视照片）。场景里还多了相机和三盏灯。

**关键检查**：参考图上那只熊，应该和你的模型**高度差不多、位置差不多**（熊头顶对齐模型头顶，脚底对齐地面 z=0）。差一点点不要紧，选中参考板按 `S` / `G` 微调即可。

**如果报错**：把红字截图发我。同时你还可以用下面的手动办法。

**如果参考图没出来**：说明脚本找不到图片，不影响建模（后面手动放）。

**如果参考图看起来左右反了或上下颠倒**：选中那块板子，按 `S` `X` `-1` 回车（左右翻）或 `S` `Y` `-1` 回车（上下翻）。

### 1.3 手动兜底（脚本失败时用，30 分钟）

在 Layout 里操作。**每放一个球，都按这三步**：

1. `Shift+A` → 网格 → **UV 球**（球会出现在鼠标位置，半径 1）。
2. **改大小**：按 `S`，输入第一个数，按 `Tab`，输入第二个数，按 `Tab`，输入第三个数，回车。
   （例：头 → `S` `3.1` `Tab` `2.65` `Tab` `2.0` `回车`）
3. **挪位置**：按 `G`，输第一个数，`Tab`，第二个数，`Tab`，第三个数，回车。

| 部件 | 按 `S` 缩放（X, Y, Z） | 按 `G` 位置（X, Y, Z） |
|---|---|---|
| 头 | 3.1, 2.65, 2.0 | 0, 0, 7.78 |
| 吻（嘴周围那一坨） | 1.3, 1.1, 0.85 | 0, -2.4, 6.90 |
| 躯干 | 3.3, 2.8, 1.95 | 0, 0, 4.00 |
| 左耳 / 右耳 | 0.5, 0.3, 0.65 | ∓2.6, 0.5, 8.60 |
| 左臂 / 右臂 | 0.75, 0.75, 1.15 | ∓2.9, -0.2, 4.40 |
| 左腿 / 右腿 | 1.3, 1.3, 1.3 | ∓1.6, -1.2, 1.40 |

> 「∓」的意思是：左边那只用负号（-2.6），右边那只用正号（+2.6）。
> 表里填的是**半径**（脚本里用的是直径，正好差 2 倍，别搞混）。

全部选中（`A`）→ `Ctrl+J` 合并成一个 → 属性面板「修改器」（扳手图标）→ 添加修改器 → 生成 → **重构（Remesh）** → 模式选 **Voxel**，体素大小 `0.12` → 点右边箭头 → 应用。

### 1.4 对照参考板修轮廓（今天最重要的一步）

现在你有一个"面团"，但可能太胖、太瘦、腿太短。修正方法只有两个动作：

1. **切前视图**（数字键盘 1）。确认右上角写着 **正交/Orthographic**（不是透视）。
2. 选中小熊 → 模式下拉框（左上角）选 **雕刻模式（Sculpt Mode）**。
3. 左侧工具栏选 **抓取（Grab）** 笔刷。
4. 按住鼠标左键拖，把脸颊往外拉、把腿往下拉。

**判断标准（只看这三处）**：
- 耳朵尖对齐参考图耳朵尖；
- 脸颊最宽处对齐参考图最宽处；
- 脚底对齐参考图脚底（参考图底边）。

对不上就继续拉。**这一步值得花 40 分钟**，因为它是整只熊的地基。

> 小技巧：把参考板材质的不透明度调低一点会更好看清。选中参考板 → 属性面板「材质」→ 拉到最下面「设置」→ 混合模式改 **Alpha 混合** → 上面「基础色」的 A 值改成 0.5。

### 1.5 存盘

`Ctrl+S` → 存到 `blend\bear_day1_blockout.blend`。

### 1.6 今天常见的三个坑

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 熊看起来"扁"或"歪" | 没切正交，视图还是透视 | 按数字键盘 5 切换，或右上角点那个小坐标轴图标 |
| 拉不动，整个熊在移动 | 你在**物体模式**，不是雕刻模式 | 左上角模式下拉框改成 Sculpt Mode |
| 拉出来一道尖刺 | Grab 笔刷半径太小 | 按 `F` 然后拖鼠标，把圆圈调大 |

## 第 2 天：雕五官（5 小时）

### 2.1 先给模型"上细分"

雕刻需要更多面，否则雕出来是马赛克。

1. 选中小熊 → 属性面板 **修改器**（扳手）→ 添加修改器 → 生成 → **多重分辨率（Multiresolution）**。
2. 点「细分」按钮 **5 次**（每点一次面数 ×4）。
3. 现在的面数大约 50 万，够雕。

> 电脑卡就只点 4 次。

### 2.2 雕刻顺序：先大块，后小块（一定按顺序）

**第 1 轮：大块（1.5 小时）**
- 笔刷：**黏土条（Clay Strips）**
- 半径：`F` 拖到约 1.5 cm（比耳朵略大）
- 强度：`Shift+F` 拖到 0.3
- 做什么：把脸颊压圆一点、额头压平一点、下巴收一点、后脑勺压实。

**第 2 轮：嘴和鼻子那块（1 小时）**
- 笔刷：**黏土（Clay）** 先铺，再用 **折痕（Crease）** 压边
- 半径：0.6 cm，强度 0.4
- 做什么：鼻梁微微隆起；鼻头位置留一个圆鼓包（真正的鼻头是另外装上去的）；嘴角往两边微微上扬。

**第 3 轮：眼窝（40 分钟）**
- 笔刷：**折痕（Crease）**
- 半径：0.3 cm，强度 0.5
- 做什么：在眼睛位置压两个**浅坑**，深 1.5 mm、直径 6 mm。眼珠是后面单独放进去的球，所以这里只要一个坑。

**第 4 轮：耳朵（40 分钟）**
- 笔刷：**折痕 + 黏土**
- 半径：0.4 cm
- 做什么：耳朵外缘压薄；耳朵内侧往内压出一个小窝（2 mm 深）；耳朵和头连接的那一圈压一道缝。

**第 5 轮：手脚（40 分钟）**
- 笔刷：**黏土 + 折痕**
- 做什么：手掌做成"连指手套"（没有手指）；掌心压 3 个小椭圆肉垫；脚掌底部压平（因为它坐着）；脚尖压两道浅沟。

### 2.3 三个必须遵守的规矩

1. **眼睛和鼻子先不要雕**——它们是独立的球，第 3 天再装。你现在雕了，后面会重复。
2. **对称打开**（右上角两个小箭头图标，X 那个点亮），先雕成左右一样；最后 10 分钟再关掉，做一点不对称（一只耳朵高 0.5 mm）。
3. **每 30 分钟切一次前视图 + 转一圈**，别埋头雕。新手最爱犯的错是"侧面看还好，正面已经歪了"。

### 2.4 缝线怎么来（不要用笔刷雕）

真实玩偶的缝线是"一道凹槽 + 两边压边"。你现在不用管，等到第 4 天减面之后再用"内插 + 倒角"做，会干净得多。今天只要把**耳根、腋下**的过渡压自然就行。

### 2.5 存盘 + 自检

存 `blend\bear_day2_sculpt.blend`。自检：转一圈，剪影有没有突然缺一块？耳朵厚度对不对？

## 第 3 天：马甲 + 领结 + 眼睛鼻子（4 小时）

### 3.1 先装眼睛和鼻子（30 分钟，很简单）

1. `Shift+A` → 网格 → UV 球 → `S` 缩到直径 0.55 cm。
2. `G` 移到眼窝里，稍微往里按 1 mm（让它"嵌"进去，不要凸出来）。
3. 复制一个（`Shift+D`），移到另一边。
4. 鼻子：同样一个球，压成 1.04 × 0.66 的扁椭圆，放在鼻梁下方。
5. 给这三个球各起个名字（`F2`）：`eye_L`、`eye_R`、`nose`。

### 3.2 做马甲（1.5 小时）

1. 选中小熊 → `Shift+D` 复制一份 → `F2` 改名 `vest`。
2. 给 `vest` 加 **缩裹（Shrinkwrap）** 修改器，目标选小熊，偏移 `0.35`（cm）。应用。
3. 进雕刻模式，用 **抓取** 把上身"撑"成马甲的形状（上窄下宽）。
4. 裁边（用「刀」工具 `K`，或者直接在雕刻模式用「线条」笔刷压出边界）：
   - **V 领**：从肩膀往中间切一个 V，最低点在胸口；
   - **袖口**：在胳膊中段横着切一圈；
   - **下摆**：在肚子最下面切平，前面略低、后面略高。
5. 加厚：修改器 → 生成 → **实体化（Solidify）**，厚度 `0.2` cm，偏移 -1。应用。

### 3.3 压出布的褶皱（40 分钟）

**简单做法（推荐）**：雕刻模式 → **黏土** 笔刷，只在 4 个地方压：
- 腋下两条向下的斜褶；
- 腰侧面一条竖褶；
- 下摆两处堆叠；
- 胸口 V 领两侧各一条。

**关键要求**：背面（徽章要贴的地方）必须**尽量平**。用 **压平（Flatten）** 笔刷把背心背面那块压平，不然你贴上去的圆徽章会变成椭圆。

### 3.4 领结（40 分钟，考验耐心）

1. `Shift+A` → 曲线 → 贝塞尔曲线。
2. 进编辑模式，把曲线拖成一条"缎带"，`Alt+S` 调粗细。
3. 属性面板 → 曲线属性 → 几何数据 → 倒角 → 深度 `0.05`（这样就变成一根有厚度的带子）。
4. 复制两条做左右两翼，各旋转 25°。
5. 中间那个结：加一个小立方体，`Ctrl+B` 倒角。
6. 位置：V 领正中，往身体外凸出 2 mm。

### 3.5 存盘

`blend\bear_day3_dressed.blend`。

## 第 4 天：减面 + 铺平（4 小时，最抽象的一天，慢点）

### 4.1 为什么要做这两件事（先看懂再动手）

- **减面**：现在模型 50 万面，太密。长毛的时候，每一根毛都要"知道"自己长在哪个面上，面太乱毛就炸。所以要减到 1.5 万面左右的"干净面"。
- **铺平（展 UV）**：贴图是一张平面图（像地图），模型是立体的（像地球仪）。要贴上去，必须先把地球仪"剪开摊平"。这个摊平的动作就叫 **UV 展开**。

### 4.2 减面（30 分钟）

1. 选中小熊 → 属性面板 **修改器** → 添加修改器 → 生成 → **四边形重构（Quadriflow Remesh）**。
2. 目标面数填 `12000`，勾上「保留锐边」。
3. 点「应用」。

> 如果重构出来很丑（耳朵烂了、腿断了），别慌：改用 修改器 → 生成 → **重构（Remesh）** → Voxel 0.08，再用 修改器 → 生成 → **减速（Decimate）** 减到 15000。效果差一点点但不会崩。

### 4.3 给熊身铺平（30 分钟）

1. 进编辑模式（`Tab`）→ `A` 全选。
2. `U` → **智能 UV 投影（Smart UV Project）** → 角度 `66` → 确定。
3. 切到 **UV 编辑** 工作区（顶部标签），你会看到一堆摊平的碎片。不用管它长得丑不丑，能用就行。

### 4.4 给马甲铺平（1 小时，要手工）

马甲必须按"真实裁片"摊平，否则徽章会贴歪。

1. 选中马甲 → `Tab` 进编辑模式。
2. 选中要"剪开"的边（侧缝、肩缝），按 `Ctrl+E` → **标记缝合线（Mark Seam）**。缝的位置：左右两侧各一条竖线、两个肩膀各一条。
3. `A` 全选 → `U` → **展开（Unwrap）**。
4. 现在去 UV 编辑区看：背面那块应该是一个接近长方形的整片。

### 4.5 检查（30 分钟）

1. 给马甲加一个棋盘格贴图（属性面板 → 材质 → 基础色右边的小圆点 → 图像纹理 → 新建 → 生成类型选"棋盘格"）。
2. 看棋盘格：格子的长宽应该接近正方形。如果某个地方被拉成长条，说明那里 UV 拉伸了，回去重新标缝合线。

### 4.6 存盘

`blend\bear_day4_uv.blend`。

## 第 5 天：长毛（6 小时）

### 5.1 毛发在哪里

选中小熊 → 属性面板最上面那排图标 → 找到 **粒子属性**（图标是几个小点，在「修改器」扳手右边两格）→ 点 **+** 新建 → 类型选 **毛发（Hair）**。

### 5.2 第一层：打底（短毛）

| 参数 | 位置 | 填什么 |
|---|---|---|
| 数量（Number） | 粒子属性 → 发射 | `6000` |
| 毛发长度（Hair Length） | 同上 | `0.25`（cm） |
| 子级（Children） | 粒子属性 → 子级 | 渲染数量 `25` |
| 成束（Clumping） | 子级 → 成束 | `0.1` |
| 粗糙（Roughness） | 子级 → 粗糙 | `0.004` |

### 5.3 第二层、第三层（复制系统）

1. 在粒子属性面板，点粒子系统名字右边的下拉箭头 → **复制**。
2. 改成长度 `0.4`、数量 `4000`、子级 `40`、成束 `0.25`。
3. 再复制一层：长度 `0.6`、数量 `1200`、子级 `12`、成束 `0.35`。

> 三层毛的意思是：底层密而短（填满皮肤）、中层是主体、表层稀疏（破轮廓）。只有一层会像"草坪"。

### 5.4 梳毛流（最影响"像不像"，1.5 小时）

1. 选中小熊 → 模式下拉框 → **粒子编辑（Particle Edit）**。
2. 左侧工具栏选 **梳理（Comb）**，按 `F` 把笔刷调到 1 cm 左右。
3. 按区域梳：

| 区域 | 往哪梳 |
|---|---|
| 头顶 | 从中心往四周，稍微往后 |
| 脸颊 | 往下、稍微往外 |
| 嘴巴周围 | 从鼻梁往两边、往下 |
| 耳朵 | 从耳根往耳缘，耳缘稍微上翘 |
| 胳膊和腿 | 顺着往下 |
| 肚子 | 往下 |

**每个区域 20 秒就够了**，梳太久会变成"刚洗完吹过头的假毛"。

### 5.5 毛长权重（让某些地方毛短一点，30 分钟）

**为什么要做**：真实的熊，耳朵边缘、鼻子周围、手掌心的毛都比身上短；马甲下面被布压住，毛几乎是平的。全身上下一个长度，一眼就假。

**怎么做**：

1. 选中小熊 → 属性面板「物体数据」（绿色三角图标）→ 找到 **顶点组** → 点 **+** 新建 → 双击改名 `fur_len`。
2. 左上角模式下拉框 → **权重绘制（Weight Paint）**。
3. 看左上角工具栏：有个 **Weight（权重）** 数值，**先把它改成你要的数值，再往模型上刷**。
   - 刷成 **蓝色 = 0**（没毛），**红色 = 1**（全长的毛）。
   - 刷错了？按住 `Ctrl` 刷是"擦掉"，或者直接刷成 1 再重来。
4. 按下面这张表刷：

| 区域 | Weight 填 | 刷完颜色 |
|---|---|---|
| 耳朵边缘 | 0.5 | 偏绿 |
| 鼻子周围 | 0.3 | 青绿 |
| 眼睛周围 | 0.45 | 绿 |
| 脚底、手掌心 | 0.05 | 深蓝 |
| **马甲盖住的整个躯干** | **0.3** | 青绿（不刷这层，毛会从布面穿出来） |
| **马甲背面徽章那一块** | **0.08** | 深蓝（徽章是从毛里浮出来的，不是贴在毛上） |
| 其余地方 | 不用刷（默认 1） | 红 |

5. 回到粒子属性 → 每个粒子系统里都有「顶点组」→ **长度（Length）** → 选 `fur_len`（三层毛都要选一遍）。

> 检查方法：渲一张正面，看手心和耳朵是不是明显比身上短。是就对了。

> 最后那条（徽章区毛长 0.08）是"像不像"的关键：真实的徽章是绣在布上、把毛压平的，不是浮在毛上面的。

### 5.6 毛发颜色（20 分钟）

1. 选中小熊 → 材质属性（红色圆球）→ 新建材质。
2. 表面选 **头发 BSDF（Principled Hair BSDF）**。
3. 参数：黑色素 `0.28`、红色素 `0.55`、粗糙度 `0.35`、径向粗糙度 `0.7`、涂层 `0.2`。

（不想调参数也行，默认值先看效果，第 7 天再统一调色。）

### 5.7 渲染一张看看（30 分钟）

1. 右上角渲染引擎选 **Cycles**（比 EEVEE 慢但毛更像真的）。
2. 采样（Samples）填 `128`（先看效果够用，最终出图再改 512）。
3. 按 `F12` 渲染。

### 5.8 存盘

`blend\bear_day5_fur.blend`。

### 5.9 长毛的三个坑

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 毛像刺猬，一根根竖着 | 没梳毛流 / 长度太一致 | 梳；加"随机长度 15%" |
| 毛像塑料片 | 没开子级（Children） | 子级渲染数量至少 25 |
| 毛穿过马甲 | 马甲没加碰撞 | 给马甲加「碰撞」修改器，或者把马甲区毛长权重调小 |

## 第 6 天：背面徽章与文字（8 小时）

> 这一天跟"手工"没关系，是"画图 + 贴图"。慢慢来，急不得。

### 6.1 先把照片校正成正视图（40 分钟，GIMP）

1. GIMP 打开 `ref_boards\emblem_zoom_80.png`。
2. 工具栏选 **透视工具**（在"旋转"工具下面）。
3. 拉四个角，让徽章变成正圆、下面那行字变成水平。
4. `图像 > 画布大小` → 裁成正方形 → 导出 `textures\emblem_flat.png`。

### 6.2 画矢量图（4 小时，Inkscape）

1. Inkscape 打开 `emblem_flat.png`，`图层 > 重命名` 叫"底图"，把不透明度调到 40%（当描摹底稿）。
2. 新建一层，叫"线稿"。
3. **画圆环**：选「圆」工具，按住 `Ctrl` 拖出一个正圆，直径对着底图。复制两个，缩小，分别对齐内圈和外圈。
4. **环形英文**：
   - 用「文字」工具写 `DEPARTMENT OF ELECTRONIC ENGINEERING TSINGHUA UNIVERSITY`；
   - 选中文字 + 外圆 → 菜单 `文字 > 放在路径上`；
   - 字会绕着圆排。用 `Alt+方向键` 微调字距，让首尾接上。
5. **中心图形**：用「矩形」工具画方形，旋转约 8°，再用 `路径 > 差集` 挖出中间的折线。
6. **中文**：
   - 内圈"清华大学"、"电子工程系"，选字体 **华文楷体**（没有就选方正楷体、楷体）；
   - 下面的大字"清华大学电子工程系"，**不要打字，直接描**：`路径 > 描摹位图`，阈值 0.45，平滑 2，然后手工修 8 个字的转折。
7. **导出**：`文件 > 导出 PNG`，尺寸 `4096 × 4096`，透明背景 → 存成 `textures\emblem_line.png`。
8. 顺手 `文件 > 另存为` 存一份 `emblem.svg`，以后要改还能改。

> 记不住细节没关系，这一步的核心只有一句：**把每一个笔画都变成"一条线"，不是"一片糊"**。糊的贴上去就是灰块。

### 6.3 做三张图（1 小时，GIMP）

| 文件名 | 怎么来 |
|---|---|
| `emblem_albedo.png` | 新建 4096 图，填紫色 `#8A69AE`，把 `emblem_line.png` 放上去，颜色改成米白 `#E8E2D6` |
| `emblem_height.png` | 复制 albedo → 去色 → 高斯模糊 1 px → 曲线加强对比（白的地方接近纯白） |
| `emblem_rough.png` | 白线部分填 0.35，紫底填 0.85（可先用灰度近似） |

### 6.4 贴到马甲上（1.5 小时，Blender）

1. 选马甲 → 材质属性 → 新建材质。
2. 把 `emblem_albedo.png` 连到「基础色」。
3. 把 `emblem_height.png` 连到「凹凸（Bump）」的「高度」，强度 `0.35`。
4. 把 `emblem_rough.png` 连到「粗糙度」。
5. 在 UV 编辑区，把马甲背面的 UV 摆到贴图上徽章的位置——**这一步就是"贴"**。
6. 渲染一张背面看看：圆是不是正圆？字能不能认出来？

### 6.5 徽章的两个坑

| 现象 | 原因 | 修法 |
|---|---|---|
| 圆变椭圆 | 马甲背面不平 / UV 拉伸 | 回去压平背面；重新展开 UV |
| 字看不清 | 贴图分辨率不够 / 线太细 | 4K 起步；线宽至少 3 px |

## 第 7 天：打光、出图、检查（4 小时）

### 7.1 灯光（已经帮你放好了，微调即可）

脚本放了三个灯：**主光**（左上前方）、**补光**（右侧，弱）、**轮廓光**（后上方）。规则：
- 主光负责"哪里亮"；
- 补光负责"暗部别死黑"；
- 轮廓光负责"毛的边缘发亮"，这是绒毛最出效果的一笔。

太亮/太暗就改功率：选中灯 → 属性面板 → 灯光数据 → 功率。

### 7.2 渲染（1 小时）

1. 相机视图：按**数字键盘 0**。
2. 渲染属性：引擎 **Cycles**，采样 `512`，勾上 **降噪**。
3. `F12` 渲染 → `图像 > 另存为` → 存 `render\final_front.png`。

### 7.3 跟照片对比（1 小时，这一步决定你要不要返工）

1. GIMP 打开 `ref_boards\ref_front_105.png`。
2. 把 `final_front.png` 拖进去当图层，不透明度 50%。
3. 看三个地方：**耳朵尖、脸颊最宽处、脚底**。差得多就回第 1–2 天改。

### 7.4 导出（30 分钟）

`文件 > 导出 > glTF 2.0 (.glb)` → 勾上"应用修改器" → 存 `export\bear.glb`。

> 毛发导出会爆面数，先不导。要给别人看就用渲染图或视频。

### 7.5 收尾清单

- [ ] 前视图和照片叠得上
- [ ] 背面徽章是正圆、字能认出来
- [ ] 毛有长短三层，不是一根根竖着
- [ ] 有存 glb + 渲染图
- [ ] 工程文件按天存了版本

## 卡住了怎么办（对号入座）

| 你遇到的现象 | 原因 | 怎么办 |
|---|---|---|
| Blender 打开是英文，看不懂 | 默认英文 | `编辑 > 偏好设置 > 界面 > 翻译` 选简体中文（术语建议还是记英文，教程多按英文讲） |
| 模型是灰的、黑的，没有颜色 | 视图着色模式是"实体" | 右上角四个小球图标，点第三个（材质预览） |
| 在视口里看不到参考图 | 参考图在视口背面 / 被隐藏 | 按 `Alt+H` 取消隐藏；或按数字键盘 1 切前视图，它应该出现在熊后面 |
| 雕刻时整个模型在动 | 在物体模式 | 左上角模式改成 Sculpt Mode |
| 笔刷刷不动 | 模型面太少 / 笔刷半径太大 | 加 Multires 细分；按 `F` 调小笔刷 |
| 毛长在身体里面（看不见） | 粒子系统的"长度"单位不对 / 权重为 0 | 检查毛发长度是不是 0.25 这种小数（单位是 cm），检查顶点组 |
| 渲染出来一片黑 | 没有灯 / 相机没对准 | 数字键盘 0 看相机视角；把灯功率调大 |
| 电脑卡死 | 面数太高 | 关掉 Multires 的视口显示（点"视口"级别减 1）；渲染采样改小 |
| 文件打不开了 | 存盘时崩了 | 用 Blender 的 `文件 > 恢复 > 自动保存` |
| 不知道自己做到第几步 | — | 看本文每节开头的"今天的目标" |

| 词 | 一句话解释 | 类比 |
