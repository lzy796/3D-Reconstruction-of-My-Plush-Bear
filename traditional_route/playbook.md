# 玩偶重建（传统流程）实施手册

> ⚠️ 本文件已被 **[../cv_route/pipeline.md](../cv_route/pipeline.md)** 取代为主线方案（几何全部由算法产出，不再手工雕刻）。本文件保留作为摄影测量细节（COLMAP 参数、掩膜规则、徽章内容核对）的参考。

> 对象：清华大学电子工程系小熊钥匙扣（约 9–10 cm 高，米色短绒 + 紫色马甲，背面双徽章 + 中英文刺绣字）
> 素材：`assets/*.jpg`，共 64 张（详见 `assets_audit.csv` 与 `contact_sheet.jpg`）
> 方法边界：**不使用生成式/AI 三维重建**（不用 SAM3D、不用 3DGS/NeRF 出网格）。几何来自摄影测量或手工建模，材质来自照片 + 程序化/手绘，绒毛为程序化毛发。
> 目标产物：① 离线渲染级资产（Cycles 毛发）② 实时级资产（glTF/FBX，≤25k tri）③ 背面徽章/文字高清贴图集

---

## 0. 一页结论

| 判断 | 结论 | 依据 |
|---|---|---|
| 现有 64 张能否直接跑出可用模型？ | **不能作为主几何来源**，只能作辅助 | 全部为"手持生活照"：多设备/多镜头混合、f/1.4–2.2 浅景深、主体仅 180–900 px、毛向每张被手压变形、背景高纹理 |
| 最优传统路线 | **补拍 40 分钟 + COLMAP 摄影测量**（路线 1）；不能补拍则**手工建模**（路线 2） | 传统流程对采集质量极度敏感；补拍成本远低于后期修补成本 |
| 背面徽章与文字能否靠重建？ | **不能，也不需要**。它是平面刺绣，应按"贴图 + 法线 + 位移"做 | 原图徽章直径仅约 200 px，环内英文笔画 1–2 px，直接投影必糊；单张照片 + 透视校正 + 矢量化足够 |
| 绒毛质感能否从照片恢复？ | **不能**，必须程序化 | 有效分辨率下绒毛细节 < 5 px，且不同照片毛向/光照不一致 |
| 关键前置动作 | 先花 2 小时做"12 张精选图 SfM 可行性试跑"，用注册率决定走路线 1 还是 2 | 见 §2 判定门 |

## 1. 素材实测体检

### 1.1 数量与规格

- 64 张 JPEG：43 张为 4096×3072（约 1200 万像素），其余为裁切/竖幅版本（长边 2762–4160 px），3 张仅 1440 px 宽（76、77、78，微信压缩版，细节不可用）。
- EXIF 中**保留了**焦距、光圈、ISO、快门，但**相机型号与镜头型号为空**（被转存剥离）→ 无法用型号反查传感器尺寸 → 内参必须靠自标定或手动给初值。

### 1.2 镜头分组（必须分组标定）

| 组 | 焦距 | 光圈 | 张数 | 推断 | 处置 |
|---|---|---|---|---|---|
| A | 5.34 mm | f/1.6 | 24 | 设备 1 主摄（等效约 24–26 mm） | 可用，作主力 |
| B | 5.75 mm | f/2.0（27 张）、f/1.4（2 张） | 29 | 设备 2 主摄 | 可用，作主力（f/1.4 那两张景深过浅，慎用） |
| C | 1.95 mm | f/2.2 | 7 | 超广角（等效约 13 mm） | **剔除**：桶形畸变 + 主体占比小 + 透视夸张 |
| D | 无 EXIF | — | 4 | 1440 px 压缩图 / 视频帧 | **剔除** |

Excel 台账：`traditional_route/assets_audit.csv`（逐张 idx / 尺寸 / 焦距 / 光圈 / ISO / 快门 / 分组）。

### 1.3 覆盖度（看 `contact_sheet.jpg`）

- 正面 3/4 视角：约 45 张，覆盖充分。
- 背面（马甲徽章可见）：约 8 张（76、80、89、90、97、103、107、137），且多为中远景。
- 纯侧面（正 90°）：仅 1–2 张；俯视、仰视、底部：0 张；五官/耳/掌局部微距：0 张。
- 主体宽度 180–900 px，中位约 450 px；同一张内因 f/1.4–2.0 全开，只有鼻尖与脸颊平面在焦内，耳朵、脚掌常虚。
- **78、113、114 有烧录字幕**（视频截图），文字会污染特征匹配，必须剔除。
- 116 为"盒中多只小熊"，仅可作颜色参考。

### 1.4 由此得到的七条硬约束

| # | 约束 | 后果 | 对策 |
|---|---|---|---|
| 1 | 多设备 / 多镜头（4 组内参） | 单相机模型会把畸变算进结构，模型"碗状" | COLMAP `--ImageReader.single_camera 0`，按组分别建 model；超广角单独剔除 |
| 2 | f/1.4–2.2 浅景深 | 耳/脚/边缘虚化 → 特征弱、深度图断裂 | 只选"对焦在脸且清晰"的图；虚化区域用掩膜排除 |
| 3 | 手持 + 每张毛向被压变 | 同一物理表面在不同图里纹理不同 → SfM 对应点漂移，绒毛几乎无法匹配 | 补拍时用支架固定，毛向一致；不补拍时 SfM 只取"形体"不取"细节" |
| 4 | 背景强纹理 + 强虚化 | 特征点被背景吸走，相机位姿解到背景上 | 逐张掩膜（黑白二值，黑=忽略） |
| 5 | 光照跨度大（夜景霓虹 / 雪地 / 阴天 / 暖灯笼） | 无法直接烘 albedo，颜色会被"烘死" | albedo 只取中性光图（80、95、105 一类）；其余图只用于几何与相对明暗 |
| 6 | 主体仅 450 px 宽 | 绒毛、缝线细节 < 5 px，物理上不可恢复 | 绒毛/缝线全部程序化；纹理靠"低频 albedo + 高频程序化细节" |
| 7 | 视频帧烧录字幕（78/113/114） | 假特征点 | 剔除 |

### 1.5 实测配色（供材质起点，非最终值）

| 部位 | 实测 sRGB | 建议 albedo 起点 |
|---|---|---|
| 熊身短绒（受光面） | rgb(207,178,155) / (193,164,142) | `#C9A585`，粗糙度 0.75 |

| 徽章绣线（白） | rgb(167,159,150) | `#E8E2D6`，各向异性 0.5 |
| 鼻头 | 深棕近黑 | `#4A3230`，粗糙度 0.35 + 微弱清漆 |
| 眼睛 | 纯黑高光 | `#0A0A0A`，粗糙度 0.08，清漆 1.0 |

## 2. 路线选择与判定门

```
开始
 ├─ 能否补拍 40 分钟？ ── 能 ──▶ 路线 1：补拍 + 摄影测量（§3 → §4）
 └─ 不能
      ├─ 先做 2h 可行性试跑（§2.1）
      ├─ 注册率 ≥ 80% ──▶ 路线 2A：SfM 出形体 + 手工修型（§4.5 清理，不建模）
      └─ 注册率 < 80% ──▶ 路线 2B：纯手工建模 + 照片参考（§5）
```

### 2.1 可行性试跑（2 小时，务必先做）

1. 从 A/B 组挑 **12 张**：正面清晰 5 张（如 85、93、94、105、122）、背面 3 张（80、89、90）、3/4 侧 4 张（82、87、98、129）。要求：对焦在脸、无字幕、非夜景。
2. 手工掩膜（GIMP 套索，每张 30 秒，只保留小熊）。
3. 跑 §4.2–§4.3 的特征提取 + 匹配 + 建图（12 张图 3–5 分钟）。
4. **判定标准**：
   - 注册 ≥ 10/12，平均重投影误差 < 1.0 px，且相机呈环绕分布 → 走路线 1 或 2A；
   - 注册 6–9 张、点云只有正面"半张壳" → 走路线 2B（别硬撑，SfM 修不好绒毛）；
   - 注册 < 6 张 → 直接路线 2B。

## 3. 路线 1：补拍 SOP（40 分钟，决定成败的 40 分钟）

### 3.1 器材

- 手机主摄即可（**禁止超广角/0.5×**），或相机 + 50–85 mm 等效镜头。
- 稳固三脚架；手动刻度转盘（或乐高转台、蛋糕转盘 + 贴角度纸）。
- 两盏柔光（或阴天窗边 + 白色泡沫板补光）；A4 白纸做反光板。
- 无缝灰色/白色背景纸（哑光，不要有花纹、不要有折痕阴影）。
- 固定件：细铁丝支架 / 橡皮泥 / 亚克力夹，**不要用手拿**（手会遮挡 + 每张改变毛向）。
- 比例尺：打印一张 50 mm 黑白棋盘格，放在同一平面入镜一次（用于定尺度）。

### 3.2 参数（一次性锁定，全程不动）

| 项目 | 设定 | 理由 |
|---|---|---|
| 镜头 | 主摄 1×（等效 24–26 mm 可接受） | 与素材 A/B 组一致，畸变可控 |
| 光圈 | f/8–f/11（手机不可调则用主摄 + 距离 30 cm 以上） | 让整只熊都在景深内 |
| 对焦 | 手动对焦到鼻子，锁定 | 避免每张焦点漂移 |
| 曝光 | 手动，ISO 100，快门按需（1/60 以上） | 避免自动曝光造成亮度跳变 |
| 白平衡 | 固定 5500 K | 后期 albedo 一致 |
| 格式 | RAW 或最高质量 JPEG；关闭 HDR / 夜景 / 美颜 / 降噪 / 人像虚化 | 算法降噪会"抹掉"绒毛细节，破坏匹配 |
| 主体占比 | 熊高占画面 65–75% | 有效像素最大化 |

### 3.3 拍摄清单

| 圈 | 俯仰角 | 张数 | 步进 | 说明 |
|---|---|---|---|---|
| R0 | 0°（平视熊眼） | 24 | 15° | 主圈，必须首尾重叠 |
| R1 | +30°（俯） | 16 | 22.5° | 拍头顶、耳背、肩线 |
| R2 | −20°（仰） | 12 | 30° | 拍下巴、腿底、坐姿接触面 |
| D1 | 背面正对 | 6 | 微调 ±10° | 徽章必须正、必须锐、必须占画面 40% 以上 |
| D2 | 局部微距 | 8 | — | 眼睛、鼻头、耳根缝线、掌垫、吊环、马甲侧缝 |

合计约 66 张。**要点**：

- 转台转、相机不动（比人绕物走更稳，背景不变 → 掩膜可复用）。
- 每张与上一张重叠 ≥ 70%；不要拍"跳角度"。
- 毛向：拍摄前用镊子把毛理顺，全程不再碰。
- 徽章那 6 张单独打一盏斜侧光，让刺绣的针脚有高光（后面做 normal/height 时对照用）。

### 3.4 落盘结构

```
capture/
  raw/        R0_000.jpg ... D2_007.jpg
  masks/      同名 .png（白=保留，黑=忽略）
  scale/      scale_ref.jpg（含 50mm 棋盘格）
  output/     （COLMAP 结果）
```

## 4. 路线 1/2A：摄影测量全流程（COLMAP）

> 等价 GUI 方案：Meshroom（免费）或 Agisoft Metashape（对小物体 + 掩膜最省事，商业授权）。下面给 COLMAP 命令行，参数可直接抄。

### 4.1 预处理

1. 统一转 sRGB、去 alpha、长边缩到 3000 px（速度提升 3 倍，精度损失可忽略）。
2. 去重：`ffmpeg`/`czkawka` 找近似帧，重复的只留一张。
3. 按镜头分组建目录：`images/A/`、`images/B/`（路线 2A 用现成素材时）。
4. 掩膜：GIMP/Photoshop 套索 → 填充黑底白熊 → 存 PNG。**注意 COLMAP 约定黑=忽略、白=使用**；先用 2 张验证方向（把一张图全涂黑，若仍能提特征说明方向反了）。
   - 半自动加速：`rembg`/SAM 出初版 → 手工修边缘（绒毛边缘必须手动，自动分割会把绒毛吃掉一圈，反而伤轮廓）。
   - 掩膜**只作用于特征提取**；稠密重建不吃掩膜，需要在融合后按包围盒裁剪。

### 4.2 特征提取与匹配

```bash
colmap feature_extractor \
  --database_path output/db.db \
  --image_path images \
  --ImageReader.single_camera 0 \
  --ImageReader.camera_model OPENCV \
  --ImageReader.mask_path masks \
  --SiftExtraction.use_gpu 1 \
  --SiftExtraction.max_num_features 16384 \
  --SiftExtraction.estimate_affine_shape 1 \
  --SiftExtraction.domain_size_pooling 1

colmap exhaustive_matcher \
  --database_path output/db.db \
  --SiftMatching.use_gpu 1 \
  --SiftMatching.guided_matching 1
```

> 66 张以内用 exhaustive；补拍后超过 120 张改用 `sequential_matcher --SequentialMatching.overlap 15 --SequentialMatching.loop_detection 1`。

### 4.3 稀疏重建（SfM）

```bash
colmap mapper \
  --database_path output/db.db \
  --image_path images \
  --output_path output/sparse \
  --Mapper.ba_refine_focal_length 1 \
  --Mapper.ba_refine_principal_point 0 \
  --Mapper.ba_refine_extra_params 1 \
  --Mapper.min_num_matches 15 \
  --Mapper.init_min_tri_angle 4 \
  --Mapper.filter_max_reproj_error 4 \
  --Mapper.abs_pose_min_num_inliers 30
```

- `single_camera 0` + `ba_refine_extra_params 1`：让每组各自估畸变，这是多设备素材唯一正确做法。
- **不要** refine principal point（小物体、弱约束，refine 会飘）。
- 结果检查：`colmap gui --database_path db.db --image_path images --import_path output/sparse/0` → 看相机是否环绕成球、有没有"两张图单独成一个 model"。
- 门槛：注册率 ≥ 85%，平均重投影误差 < 0.8 px，最大误差 < 3 px。不达标回到 §2.1 判定。

### 4.4 稠密重建

```bash
colmap image_undistorter \
  --image_path images --input_path output/sparse/0 \
  --output_path output/dense --output_type COLMAP --max_image_size 3200

colmap patch_match_stereo \
  --workspace_path output/dense --workspace_format COLMAP \
  --PatchMatchStereo.geom_consistency true \
  --PatchMatchStereo.window_radius 5 \
  --PatchMatchStereo.filter_min_ncc 0.1

colmap stereo_fusion \
  --workspace_path output/dense --workspace_format COLMAP \
  --input_type geometric --output_path output/dense/fused.ply \
  --StereoFusion.min_num_pixels 3 \
  --StereoFusion.max_reproj_error 2 \
  --StereoFusion.max_depth_error 0.05

colmap poisson_mesher \
  --input_path output/dense/fused.ply \
  --output_path output/dense/meshed.ply \
  --PoissonMeshing.trim 7
```

- 小物体的坑：`trim` 太大 → 耳朵/手指被削平；太小 → 底部拖出一层"裙边"。先 7，再按结果 ±3 调。
- 备选 `delaunay_mesher`（保形更好、噪点多），用于后续手动清理。

### 4.5 清理与重拓扑（Blender）

1. 导入 `meshed.ply` → 删除背景碎片（选中最大连通域 → `Select Linked` → `Ctrl+I` 删除）。
2. 补洞：`Fill Holes`（小洞）+ 手工桥接（被手遮挡的区域，例如右下腋下）。
3. Remesh：`Voxel Remesh` 0.3 mm 去掉噪点，再 `Quadriflow`/QuadRemesher 到 **15k–25k 四边面**。
4. 对称化：`Mirror` + `Shrinkwrap`（把重建的"歪"对称回来，玩偶本身就对称）。
5. 形体校正：照片里被手压扁/压圆的部位，用 `Sculpt > Grab / Smooth` 按轮廓复原；耳朵厚度、腿长按 §1.3 的正面图校准。
6. 输出 `bear_hi.blend`，作为后续所有烘焙的高模。

## 5. 路线 2B：手工建模（不补拍时的主线）

> 完整分步流程见 **[plan_no_reshoot.md](plan_no_reshoot.md)**（含实测比例表、Blender 初始化脚本、马甲/领结/绒毛/徽章逐步操作、验收方法）。本节为速查版；§5.2 的估算比例已被该文件的实测值取代。

### 5.1 参考板（半天）

- 选 8 张：正 4（85、93、94、105）+ 背 4（80、89、90、137）+ 3/4 侧 4（82、87、98、129）。
- 在 Photoshop 里统一到"熊高 2000 px"，按身体中线对齐，拼一张正交参考板（正面 / 背面 / 侧面）。
- 侧面参考很少 → **用对称假设**：正面轮廓左右镜像即侧面近似（玩偶近似旋转对称 + 四肢前后错位），再用 3/4 图修。
- 打印/贴到 Blender 的 `Empty > Image` 背景板上，正交相机 + `X-Ray` 对照描形。

### 5.2 比例（按实测，熊高 100 单位 = 1 dm）

| 部位 | 相对熊高 | 备注 |
|---|---|---|
| 头（含耳） | 48% | 头身比约 1 : 1.05 |
| 头球直径 | 34% | 略扁（Z 压 0.92） |
| 耳直径 | 11% | 位于 10 点/2 点方向，厚 4% |
| 吻部突出 | 6% | 中心偏下 8% |
| 躯干（马甲内） | 30% | 上窄下宽 |
| 手臂长 | 22% | 下垂、略外张 12° |
| 腿（坐姿前伸） | 20% | 脚掌朝前上 |
| 吊环 | 直径 8% | 细金属，0.8 mm |

### 5.3 建模顺序

1. **Blockout**：球 + 胶囊 + 圆柱拼出头/躯干/四肢/耳；`Boolean` 合并 → `Voxel Remesh 0.5` → `Smooth`。
   （不要一上来就细分曲面，先保证剪影对：把正交参考板垫在下面用 `Grab` 拉轮廓。）
2. **Sculpt 中模**：`Draw` 加颊部、`Crease` 压鼻梁、`Inflate` 修耳根；用"剪影检查"——视图切到前/侧，与参考图叠合，误差 < 2% 熊高。
3. **细节**：
   - 缝线：沿中线、耳根、腋下、胯部用 `Inset + Bevel` 压出凹槽（宽 0.6%、深 0.3%），后面直接进法线。
   - 眼睛：半球体嵌入 2 mm，外圈压一道凹边（真实玩偶眼睛是缝/粘上去的，有边界高光）。
   - 鼻头：椭圆锥（宽 8%、高 5%）+ 三角楔形，底部做"Y 形嘴线"凹槽。
   - 掌垫：掌心 3 个小椭球 + 压边。
4. **马甲**：复制躯干 → `Shrinkwrap` 外扩 1.5 mm → 用 `Knife` 沿 V 领、袖口、下摆裁出边界 → `Solidify 2 mm` → 侧缝、肩缝单独留边（为 UV 裁片准备）。
5. **吊环**：`Torus` + 一个开口环（torus 截断 30°），金属材质 `Metallic 1 / Roughness 0.25`。
6. **统一减面**：`Decimate (Planar)` 只在平直区用；最终实时版 ≤ 25k tri，渲染版可留 60k。

## 6. UV 与贴图烘焙（两条路线共用）

1. **UV 拆分**：
   - 熊身：一张 4K（`Smart UV Project`，角度 66°，边距 0.003），或 xatlas 自动打包（更省空间）。
   - 马甲：**按真实裁片展开**（沿侧缝/肩缝断开）——这样徽章在 UV 上是正圆，贴上去零拉伸。这是本工程最关键的一个 UV 决策。
2. **烘焙**：高模 → 低模，Blender Cycles 或 Marmoset：
   - Normal（切线空间，Y+ 按引擎定）
   - AO（贴图乘到 albedo 的暗部）
   - Curvature / Pointiness（做缝线、绒毛根部遮罩的利器）
   - Thickness（绒毛透光用）
3. **贴图集规划**：

| 贴图 | 熊身 | 马甲 | 说明 |
|---|---|---|---|
| BaseColor | 4096² | 4096² | 徽章全在马甲上，必须 4K |
| Normal | 4096² | 4096² | 含缝线 + 刺绣针脚 |
| Roughness / Metal / AO | 打包成 ORM 2048² | 4096² | 马甲徽章区要单独粗糙度 |
| Height | 2048² | 4096² | 刺绣 0.3–0.5 mm 起伏 |
| FurFlow（RG = 毛向） | 2048² | 2048² | 绒毛 shell/各向异性必需 |

4. **去光照（重要）**：照片投影得到的 albedo 带光照。做法：
   - 用中性光图（80/95/105）做投影源；
   - 在 Blender 里对投影结果做"高频/低频分离"：低频乘一个均匀化系数（对齐到 0.6 灰），高频（绒毛纹理）保留；
   - 或者干脆只取"颜色"不取"明暗"：在 Substance 里用 `Color picker + Fill` 铺基色，再用照片做 `Overlay 8%` 的细节层。

## 7. 绒毛（本项目观感的核心）

### 7.1 离线版（Cycles，做展示渲染）

| 参数 | 值 | 说明 |
|---|---|---|
| 毛发长度 | 3–6 mm（分层：底层 2.5 mm，中层 4 mm，表层 6 mm） | 10 cm 玩偶的真实毛高约 4–6 mm |
| 导引毛数量 | 8k–15k 根 | 分布密度 60–100 根/cm² |
| Children | 30–50，`Clumping 0.25`，`Shape 0.85` | 成束感；clumping 太高会像湿毛 |
| Roughness（发丝） | 0.004–0.008 | 控制毛躁度 |
| 随机 | 长度 ±15%、方向 ±5°、粗细 ±10% | 避免"梳过头"的假 |
| 材质 | Principled Hair BSDF：Melanin 0.28、Melanin Redness 0.55，Roughness 0.35，Radial Roughness 0.7，Coat 0.2 | 米色绒的柔和光泽 |
| 颜色 | 根部 `#A8846A` → 毛尖 `#DCC0A0`（`Tip Mix` 0.35） | 绒毛自然有"根深尖浅" |
| 透光 | Translucency 0.1–0.15 | 逆光时的绒感来源 |
| 毛向 | 从鼻梁向后/向下，头部呈放射，四肢向下 | 用 `Comb` 梳出毛流，别用默认法线方向 |

渲染设置：Cycles，`Hair > Shape: Strand`（不要 Ribbon，细毛更真实），`Subdiv` 2，`Max Bounces 12`；采样 512 + `Denoise`。

### 7.2 实时版（glTF / UE / Unity）

两条路，按目标平台选：

**A. Shell Fur（推荐，兼容性最好）**
- 8–10 层，每层沿法线外扩 `i * 0.4 mm`，最后一层 3.5 mm；
- 每层用 4 张不同的毛束 alpha 图（tile 2×2），每层 UV 偏移 + 缩放 3–7%，破掉重复感；
- 底层不透明，越往上越透明（`Alpha = 1 - i/N`，配合 `AlphaTest` 0.3）；
- 顶点着色器里按 `FurFlow` 贴图做"倒伏"（wind/gravity 偏移 0.2 mm）。

**B. Fur Card + 各向异性**
- 在身体上贴 300–600 张卡片，卡片用 `FurFlow` 定向；
- 材质：`Anisotropy 0.6`，切线方向 = 毛向；双层法线（布纹基础 + 毛束）；
- 适合远景/低配，近景会露馅。

**性能预算**：熊身 15k tri + 马甲 3k tri + 10 层 shell（每层 1 draw call 用实例化）→ 移动端 60 fps 无压力。

### 7.3 马甲绒毛（与熊身不同！）

马甲是毛巾布/羊羔绒质感，比熊身更密、更短、更"结块"：
- 毛长 2–3 mm，密度 ×1.5，`Clumping 0.45`（结块感）；
- 徽章区域毛长压到 0.5 mm 并压低（真实玩偶徽章处毛被绣线压平）→ 用 `Weight Paint` 做长度权重图；
- 这是"像不像"的关键：**徽章必须从毛里"浮"出来，而不是贴在毛上**。

## 8. 背面徽章与文字（第二核心）

### 8.1 内容核对（已从 80 号图放大确认）

| 元素 | 内容 |
|---|---|
| 左徽章（清华校徽） | 外圈 `TSINGHUA UNIVERSITY` + `1911-`；内圈八字校训「自强不息 厚德载物」环绕五角星 |
| 右徽章（电子系徽） | 外圈 `DEPARTMENT OF ELECTRONIC ENGINEERING TSINGHUA UNIVERSITY` + `1952-`；内圈上「清华大学」下「电子工程系」，中心为方形叠层图形（书页/晶圆造型） |
| 大字 | 清华大学电子工程系（楷体风格，笔画带书写感，字高约 6 mm） |
| 小字 | Electronic Engineering, Tsinghua University（衬线体，字高约 2.5 mm） |
| 底色 | 紫色绒布，实测 rgb(112,84,146) → `#8A69AE` |

### 8.2 为什么必须矢量化

徽章直径在原图中仅约 200 px，环内英文笔画 1–2 px；大字汉字实高约 55 px、笔画 5–7 px。底下还是毛巾布 + 绣线反光 → 直接投影只会得到灰糊块。**矢量化重建 + 4× 超采样**是唯一出路。

### 8.3 制作步骤

1. **取图**：80（最正）+ 89/90（侧光，看针脚）。用 GIMP 透视工具校正成正视；把徽章区裁成 1024 px 见方。
2. **描摹**：
   - 圆形环用同心圆 + `Text on Path` 沿弧排字；两处 `1911-` / `1952-` 单独定位。
   - 中心图形用布尔运算重建（矩形 + 折叠线），不要手绘近似。
   - 中文大字优先**描摹路径**（比找字体更像），字体近似可用「华文楷体 / 方正楷体」；英文衬线用 Times New Roman / 思源宋体，再逐字微调。
   - 校徽/系徽可用官方矢量稿作底（校内有现成 AI/SVG），但**必须核对**：这只玩偶把 `1952-`、外圈英文、内圈"电子工程系"都排进去了，与某些官方版本不完全一致。
3. **导出三张图**（每张 4096²）：
   - `emblem_albedo.png`：白线 `#E8E2D6`，紫底 `#8A69AE`；
   - `emblem_height.png`：灰度高度（绣线凸起 0.3–0.5 mm，笔画中央高、边缘 0）；
   - `emblem_mask.png`：用于 roughness / 各向异性 / 毛长抑制。
4. **刺绣质感**：
   - 针脚：`Wave texture` 45° 旋转 + `Noise` 扭曲，频率 8–12 线/cm，叠加到 height；
   - 法线：height 求梯度 → `Normal Map`，强度 0.6；
   - 各向异性：切线沿针脚方向，`Anisotropy 0.5–0.7`，`Roughness 0.35`（丝线高光比布亮）；
   - 边缘：徽章外圈加 0.3 mm 的"绣线包边"高度，阴影会自己出来。
5. **贴合**：
   - 马甲 UV 已按裁片展开 → 徽章在 UV 上是正圆，直接放；
   - 若 UV 是圆柱/球形展开，必须在 UV 里做水平压缩补偿（`cos` 修正），否则贴上去两边被拉宽；
   - **位移**：`Displacement` 0.4 mm + `Subdivision 3`（只在徽章区），让刺绣真的有厚度；
   - 缝线：沿 UV 裁片边缘画针脚（重复短线段），一起进法线。
6. **检查**：把相机摆到与 80 号图相同方位渲染，与照片 1:1 对比；徽章字必须可读，边缘要有"毛压下去"的过渡。

## 12. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 注册率 < 50% | 掩膜方向反了 / 背景抢特征 / 虚化图混入 | 全黑图验证掩膜方向；剔除虚化图；`--SiftExtraction.max_num_features` 提到 32768 |
| 模型呈"碗状"或扭曲 | 单相机模型混了多组内参 | `single_camera 0`；按镜头分目录分别建 model；固定 principal point |
| 只有正面有面片 | 背面照片不足（本项目现实） | 用对称 + Mirror；背面只做"马甲 + 徽章"贴图，不求几何 |
| 稠密模型有"飞点/裙边" | Poisson trim 太小 | `--PoissonMeshing.trim` 加到 10–12，再用 Blender 手动裁 |
| 绒毛渲染像"塑料草" | 毛太长 / 太直 / clumping 过高 | 长度降到 4–5 mm，加 `Roughness`，clumping 0.2，加 3 层不同长度 |
| 徽章糊 | 直接投影了低分辨率照片 | 走 §8 矢量化；贴图至少 4K，刺绣做位移 |
| 实时版毛"穿帮"到背景 | shell 层数与 alpha 衰减不匹配 | 减少层数、`AlphaTest` 提到 0.35、最后两层用更细的 alpha 图 |
| 颜色偏粉/偏蓝 | albedo 取自暖光/夜景 | 只用 80/95/105 这类中性光图取样 |
